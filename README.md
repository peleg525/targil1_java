# EX1 - Workshop Registration (Vanilla)

Implementation of the workshop registration API in plain Java (JDK 25).

- `model` - implementation of Instructor, Student, Workshop and Team
- `logic` - `WorkshopSystemImpl`, implementation of WorkshopSystem
- `artifacts` - the compiled jars

Run the tester (Windows):
```
java -cp "workshop-tester.jar;logic-1.0.jar;model-1.0.jar;artifacts\workshops-model.jar;artifacts\workshops-logic.jar" patmal.workshops.main.Main
```
